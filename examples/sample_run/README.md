# Sample run

This is a deliberately small excerpt from a completed 0.5 m/s simulation run.
It demonstrates the output schema without committing the full image sequence.

The original run used:

- commanded forward speed: 0.5 m/s
- travel distance: 2.0 m
- camera rate: approximately 30 Hz
- saved frames: 146

`frames.csv` is retained in full because it is small. Only three representative
PNG frames are included here; the full dataset should be distributed through a
dataset archive rather than Git.
